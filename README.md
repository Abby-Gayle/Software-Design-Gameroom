So, we can support multiple games, teams, and players on different operating systems. When deciding which operating system was best to use, I had considered the pros and cons of each system. Working through the design document did help me when making the code knowing what pattern to use and how I should implement it.
If I went back and revised this document again, I would make the chart of looking through each operating system a bit better I don't think the wording was well enough. I interoperated the users' needs by figuring out what was needed. It's important to consider the needs because we need to know what the client wants solved or in their application. This is how I designed the software based on what the client wanted and then creating smaller steps and doing each one as I developed the design.
